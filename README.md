# MedicalDeviceCalibrationAPI

This project is a C# ASP.NET Core application that allows users to check the calibration status op medical devices.

Features:
-Enter medical; device information and calibrate dates.
-Check whether the calibration is Current or Overdue.
-Display calibration results on a webpage. 
-Retrieve sample device information through a JSON API.

How to Run:
1. Open MedicalDeviceCalibrationAPI.slnx in Visual Studio
2. Run the application using HTTPS
3. Open the webpage to check calibration status.
4. To test the API visit
   https://localhost:7282/api/MedicalDevices (port may vary)
   
The webpage and API operate independently.

Documentation:
The repository includes UML diagrams, a wireframe, functional requirements, and a test plan.
